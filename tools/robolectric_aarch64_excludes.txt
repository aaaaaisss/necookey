# Linux aarch64 で除外する JVM テスト（ルート build.gradle が読む）。1 行 1 件「モジュール:Class.method」、# はコメント。
# 理由: Robolectric のネイティブランタイム（SDK 35 以降はアプリ起動時 AndroidTestEnvironment.setUpApplicationState で必ず読む libandroid_runtime、
#       およびネイティブ SQLite）が Linux aarch64 非対応（AssertionError "The Robolectric native runtime is not supported on Linux (aarch64)"、
#       robolectric#9166、公式対応なし）。レガシー SQLite（sqlite4java）も aarch64 の native を持たないので SQLiteMode.LEGACY でも回避不可。
#       sdk を 34 以下に下げれば一部は動く可能性があるが、テストの @Config(sdk=[35]) を変えることになるので見送り。
# 併せて aarch64 では robolectric.conscryptMode=OFF（Conscrypt に linux-aarch_64 の JNI が無く UnsatisfiedLinkError になるため）。
# x86_64 Linux / mac / CI では除外も設定変更もしない（全件実行）。2026-10-28 aarch64 サンドボックスで確認。
